# Shiori (栞)

A lightweight, native iOS bookmark and digital asset manager designed with Apple Human Interface Guidelines in mind. Shiori lets you save, organize, and quickly retrieve links, notes, images, and documents in a unified workspace.

---

## Features

- **Multi-Type Stashing:** Save links, quick notes, photos, and files in a single unified list.
- **Apple HIG Floating Ornament:** Modern floating search capsule with a detached circular action menu built with system materials.
- **Quick Look & Image Previews:** Preview stored images and documents directly within native system dialogs.
- **Fast Sorting:** Organize your collection on the fly by Date Modified or Name.
- **SwiftData Persistence:** Local-first, fast, and responsive storage using Apple's SwiftData framework.
- **Native Contextual Actions:** Open links directly in Safari, copy payloads to clipboard, edit metadata, or delete with native system alerts.

---

## Tech Stack

- **Platform:** iOS 17.0+
- **Language:** Swift 5.9+
- **Frameworks:** SwiftUI, SwiftData, UniformTypeIdentifiers, PhotosUI
- **Design Language:** Apple Human Interface Guidelines (Materials, Spring Animations, System Symbols)
